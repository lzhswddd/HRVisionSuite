# HrFluentWidgets
HrFluentWidgets is a Python package designed to provide a collection of reusable and customizable widgets for building modern and fluent user interfaces.

## Features
- A variety of pre-built widgets for common UI components.
- Customizable styles to match your application's design.
- Easy integration with popular Python GUI frameworks.

## Installation
Install the package using pip:
```bash
pip install hrfluentwidgets
```
